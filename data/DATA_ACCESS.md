# Data scope and restrictions
The full WRDS/CRSP/S&P price library remains in the private local project. Redistribution permission has not been established; it is excluded here. The CSV sample is fictional and cannot reproduce the real forecast or a three-year fit. Do not use it as financial evidence.

frozen_aggregate_inputs.json contains real aggregate statistics. These allow the exact final rounded forecast, OLS coefficients and volatility arithmetic to be reproduced offline without an account or AI. They do not independently validate underlying raw prices, original publication vintages, row selection, or historical backtest metrics. The raw-fitting code is included for a marker with lawful access to the original input snapshot, identifiable by its hash. Requesting or providing that data is a separate licence-dependent step.

Do not describe this package as a complete raw-data refit or a strict point-in-time certified backtest. No credentials or full price library are included. Rights for aggregate reporting should still be checked against institutional terms before public publication.
