# Final research model V1

The selected rule is unpenalized OLS with an intercept and one factor, unannualized population standard deviation of twenty daily log returns. The response is the simple return over six subsequent equity sessions. The ten-year local price library supports daily rolling three-year estimation. Historical input and label availability checks precede sample selection. At least130 eligible matured samples are required, with training target dates strictly before the current baseline date.

This package fixes the model rule, not permanent coefficients or the coursework point forecast. The November6 parameter snapshot is for reproducibility. No final November20 forecast or student approval is represented.

Rejected alternatives and adverse results remain in the project. Ridge, SVR and shrinkage are absent from this final rule. Relative historical performance gains are small, post-selection, and unstable recently. Overlapping labels are dependent. Snapshot vintages and reconstructed publication timing are not strict point-in-time certification.

Original price provenance: WRDS CRSP index1000502, FRED SP500 and a separately observed official S&P DJI November5 close. See data source records and manifests. Check WRDS redistribution restrictions before external submission.

The isolated implementation reads saved files only. No credentials, live account or AI subscription are needed. Prepare the pinned numerical dependencies, then follow README reproduction commands. Model uncertainty and future forecast error remain material.
